## 1. System Overview

wiki-graph-explorer is a build-time tool plus a Next.js static-export web page. Given a local
filesystem path to a Karpathy-pattern Markdown-wiki repo, it emits two static JSON assets
(`graph-data.json`, `vector-index.json`) that a `/graph` page fetches client-side and renders as
an interactive, force-directed graph with live semantic search. There is no server runtime in
production — the deployed artifact is a static site (GitHub Pages), rebuilt and redeployed
whenever the source vault changes.

## 3. Data Sources

| Source | Format | Notes |
|---|---|---|
| Public vault markdown files | `.md` + YAML frontmatter (`title`, `tags`, `status`, `Related`, `Referenced By`) | Karpathy-pattern raw→wiki ingestion; the only content ever built for deployment |
| Private `second-brain` vault | Same format | Local dev iteration only (sibling path, e.g. `../second-brain`); never committed or deployed |

*(to be completed during implementation — authentication, authorization, network access, secrets management)*

No authentication for MVP — unlisted-URL access model. The primary safety boundary is content
isolation: the deployed instance is built only from the dedicated public vault, never the
private `second-brain` vault (see design-notes.md for rationale).
